# Email Configuration Manual

This project sends reservation confirmation emails using SMTP.

## Gmail Test Configuration

For development and testing, Gmail can act as the restaurant's email account.

Required Gmail SMTP settings:

- SMTP server: `smtp.gmail.com`
- Port: `587`
- Security: STARTTLS
- Authentication: Gmail address + Google App Password

## 1. Enable Gmail App Password

The Gmail account must have 2-Step Verification enabled.

Open:

https://myaccount.google.com/apppasswords

Create an App Password such as:

Restaurant Reservation App

Google generates a 16-character App Password.

Do not use the normal Gmail password.

Never save or commit the App Password to GitHub.

## 2. Configure PowerShell

Before starting the application, set:

$env:MAIL_SERVER="smtp.gmail.com"
$env:MAIL_PORT="587"
$env:MAIL_USERNAME="restaurant@gmail.com"
$env:MAIL_PASSWORD="GMAIL_APP_PASSWORD"
$env:MAIL_FROM="restaurant@gmail.com"
$env:RESTAURANT_EMAIL="restaurant@gmail.com"

Replace the example Gmail address with the restaurant's Gmail address.

Replace `GMAIL_APP_PASSWORD` with the App Password generated by Google.

## 3. Meaning of the Email Addresses

`MAIL_USERNAME`

The restaurant email account used to log in to the SMTP server.

`MAIL_FROM`

The email address shown as the sender.

`RESTAURANT_EMAIL`

The restaurant's own email address.

The customer's email is NOT configured here.

The customer enters their email address in the reservation form.

Example:

Restaurant:
restaurant@gmail.com

Customer:
customer@yahoo.com

Email:

From: restaurant@gmail.com
To: customer@yahoo.com

## 4. Start the Application

After configuring the environment variables:

python app.py

Make a test reservation using an email address that you can check.

The customer should receive an email containing:

- Customer name
- Booking reference
- Reservation date
- Reservation time
- Number of guests
- Special requests

Also check the Spam/Junk folder.

## 5. Real Restaurant Configuration

For a real restaurant, first determine its email provider.

Examples:

- Gmail / Google Workspace
- Microsoft 365 / Outlook
- Hosting provider email
- Custom domain email

Ask for:

- SMTP server
- SMTP port
- Encryption method
- SMTP username
- App Password or SMTP credential

Do not ask the customer to send their normal email password.

For example, a restaurant may use:

booking@restaurantname.se

Then configure the SMTP settings supplied by the restaurant's email provider.

Do not assume that a custom-domain email uses Gmail SMTP.

## 6. Security

Never put real passwords in:

- app.py
- agent.py
- .env.example
- Git
- GitHub

Real credentials should be stored as environment variables or deployment secrets.

`.env.example` contains only example values and can be committed.

## 7. Troubleshooting

If the reservation works but no email arrives:

1. Check Spam/Junk.
2. Check the recipient email address.
3. Check MAIL_SERVER.
4. Check MAIL_PORT.
5. Check MAIL_USERNAME.
6. Verify the App Password.
7. Check the Flask terminal for SMTP errors.
8. Check the sender's Sent folder.

For Gmail use:

smtp.gmail.com
Port 587
STARTTLS
